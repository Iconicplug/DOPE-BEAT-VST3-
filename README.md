# DOPE BEAT by ICONICO (VST3, Windows)
1. Sube todo este contenido a un repo de GitHub (rama main).
2. Actions -> "Build DOPE BEAT" -> descarga el artefacto `DOPE-BEAT-VST3-Windows`.
3. Copia la carpeta `DOPE BEAT.vst3` a `C:\Program Files\Common Files\VST3\`.
4. Ableton Live: Preferencias > Plug-ins > activar VST3 y Rescanear.
MIDI (para cambiar slots): notas 36-63 = Time slots 1-28, notas 72-103 = Volume slots 1-32.
En Ableton el MIDI solo llega al plugin si lo pones en una pista MIDI (despues de un instrumento) o en un Instrument Rack.
